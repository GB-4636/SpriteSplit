# SpriteSplit

[English](README.md) | **中文**

SpriteSplit 是一款桌面工具，用于清理不符合严格间距或对齐规则的 AI 生成切图表。它通过 PNG 透明度检测独立的非透明区域，允许你可视地修正和整理边界框，可选择通过 AI 生成资产描述进行丰富，并导出结构化元数据和裁剪后的切图。

## 特色

- 专为不规则 AI 生成的切图表设计，而不仅仅是整齐排列的图集
- 通过透明度连通区域检测切图候选区域
- 可选择仅导出元数据，或元数据加裁剪图
- 保存原始图像生成 prompt，用于编目和 AI 命名上下文
- 支持手动修正：框创建、拖拽、调整大小、排序和命名
- AI 描述生成为可选功能，且支持可插拔的 AI 提供商

## 技术栈

- `Tauri 2`
- `React + TypeScript + Vite`
- `Python + Pillow + NumPy`

## v1 功能范围

- 通过桌面应用导入 PNG
- 基于透明度阈值的切图区域检测
- 按行或列优先排序
- 可视化编辑切图边界框
- 撤销和重做历史
- JSON 和 CSV 导出
- 可选的裁剪 PNG 导出
- 可选的标准化画布导出
- OpenAI 兼容的视觉端点集成，用于生成描述

## 环境要求

- Node.js 20+
- Rust 工具链（用于 Tauri 构建）
- Python 3.10+

应用按以下顺序查找 Python：

1. `SPRITESPLIT_PYTHON` 环境变量
2. `./.venv/Scripts/python.exe`
3. `./.venv/bin/python`
4. Codex 捆绑运行时路径（如果存在）
5. `python3.13`, `python3.12`, `python3.11`, `python3.10`, `python3`, `python`
6. `py -3`

如果机器上没有 Python，请在启动 `tauri dev` 前显式设置 `SPRITESPLIT_PYTHON`。

- API 密钥
- 模型名称

## 适用场景

### 游戏资产清理

你使用 Midjourney、Stable Diffusion 或其他 AI 图像工具生成了一张切图。输出是一张 PNG，切图大致按行列排列，但像素位置不规则。SpriteSplit 通过透明度自动检测每个切图区域，让你可视化确认和调整边界框，并导出统一画布尺寸的裁剪图——直接可用于游戏引擎。

### 快速资产编目

你有一大批切图表需要结构化的元数据（名称、描述、分组、标签）。逐个导入，让 Alpha 检测器识别切图，运行 AI 命名自动生成开发者友好的资产名称和描述，然后导出 JSON/CSV 接入你的资产管线。

### 切图表审核

在交付或集成资产之前，你需要确认每张切图都有有效的边界框、无重叠、命名正确。使用可视化编辑器快速扫描、选择、重排序、重命名和删除问题切图——然后导出修正后的项目文件。

### AI 绘画到游戏资产的工作流

使用 AI 生成美术资源进行游戏原型开发时，你需要一个可重复的流程：生成 → 检测 → 清理 → 导出。SpriteSplit 以最少的手动操作覆盖"检测和清理"步骤，让你专注于游戏开发而非像素级编辑。

## 操作指南

### 1. 导入切图表

点击**导入 PNG** 或将透明 PNG 拖放到画布上。SpriteSplit 会自动运行 Alpha 阈值检测并填充切图列表。

### 2. 调整检测参数

在左侧面板的**检测**区域中：
- **Alpha 阈值** — 控制哪些像素不透明度算作"内容"（值越高，检测到的区域越少）
- **最小区域面积** — 过滤掉低于指定像素阈值的细小噪点
- **排序方式** — 按行优先或列优先重排切图顺序

点击**重新检测**应用更新后的参数。

### 3. 可视化编辑切图

使用左侧面板的画布工具：
- **选择** — 单击选择切图，Shift+单击多选
- **创建框** — 在画布上拖拽绘制新的切图区域
- **移动** — 拖拽已选切图移动其边界框位置
- **调整大小** — 拖拽角部手柄调整框尺寸

在切图列表中：
- **上移 / 下移** — 调整切图顺序
- **删除** — 移除已选切图

### 4. 命名和描述切图

在右侧面板的**检查**标签中选择单个切图，手动编辑名称、分组、标签和描述。

批量命名：打开 **AI** 标签：
1. 启用 AI 提供商，填写基础 URL、API 密钥和模型名称
2. 可选填入原始生成 prompt（作为 AI 命名上下文）
3. 点击**全部命名**或**命名所选**，通过 AI 生成资产名称和描述

AI 响应按图像哈希 + 边界框 + prompt 缓存，重复运行速度很快。

### 5. 导出

在右侧面板的**导出**标签中：
1. 选择输出目录
2. 勾选选项：裁剪 PNG、标准化画布、JSON 清单、CSV 摘要
3. 点击**导出项目**
